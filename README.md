# Filter Functionality Testing

Automated test suite for validating filter functionality using WebdriverIO.

## Tech Stack

- **WebdriverIO 9.11.0** - Browser automation framework
- **Mocha** - Test runner
- **Chai** - Assertion library
- **Visual Service** - Visual regression testing

## Installation

```bash
npm install
```

## Running Tests

```bash
npm run test
```

## Project Structure

This project contains automated tests for filter functionality across web components, leveraging WebdriverIO for browser automation and Mocha for test execution.
